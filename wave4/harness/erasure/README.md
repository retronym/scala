# erasure track: program generator with metamorphic oracles

`Gen.scala` generates one small program per seed, typed by construction: a type-directed expression generator over Int/Long/Double/String/Boolean, value classes (case classes extending AnyVal, optionally generic, optionally with a universal trait), a sealed case-class hierarchy, Option, tuples, List, Array with ClassTag, Function1 and a SAM trait. Templates are a trait, an optional subtrait, an optional abstract class and one or two leaf classes, generic in one or two parameters with `@specialized` at weight `-Dw4e.spec` (default 0.25). Members: vals, vars, lazy vals, nested objects, defs with default, by-name and vararg parameters, method type parameters with ClassTag bounds, overloads distinct after erasure, overrides with super calls. Expressions: blocks with local vals, lazy vals, vars, defs and classes; lambdas and SAM literals; matches on the sealed hierarchy, tuples, Options, an extractor and type tests, with guards, nesting and alternatives; for-comprehensions over List, Option and Range; try/catch/finally and `return` through finally; while loops; tail-recursive and mutually recursive local defs; partial function literals; string interpolation; named arguments; an implicit class and an implicit parameter. `Tr.t(n, e)` records evaluation order. A member body only calls members with a smaller index, so programs terminate. `Main.run` calls every member on every instance, through the leaf type and each ancestor type, and prints the value or the exception class plus the evaluation trace.

`Driver.scala` compiles in one JVM (fresh `Global` and class loader per compilation, in-memory output, timeouts) and compares the reference output with: `nospec` (every `@specialized` removed), `novc` (`extends AnyVal` replaced by `extends AnyRef`), `separate` (one compilation per top-level unit, in order), `delambdafy-inline`, `inline` (`-opt:inline:**`, every 8th seed because it is slow) and `-Ycheck:all` (every 10th seed). A reference that does not compile while `nospec` or `novc` does is a finding, not a generator failure. Signature: rewrite, outcome kinds, exception class or normalised first error line. First occurrence of a signature is shrunk by deleting units and lines and written to `<out>/sig-*.scala`; reference crashes go to `basefail-*.scala` unshrunk.

Run: `run.sh <build/pack> <first seed> <seconds> <out dir> [noshrink] [ycheck] [inline] [dump]`, JVM options through `W4E_JAVA_OPTS` (for example `-Dw4e.spec=0`, `-Dw4e.superpoly=true`, a JaCoCo agent). `dump` writes only the reference outcome per seed to `out-<seed>.txt`; run it on two compilers (the driver classes run unchanged on the 2.13.18 jars) and compare the directories.

Measured: about 14 programs per minute per JVM with all rewrites and shrinking, about 6 when the inliner variant dominates, about 200 per minute in `dump` mode.

Not yet done: shrinking inside a line, shrinking reference crashes, the Scala 3 comparison, quarantine of hung compilations (the driver stops after three timeouts).
