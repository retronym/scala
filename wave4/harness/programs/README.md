# programs track: general program generator with metamorphic oracles

Continues the erasure spike (`../erasure/`) on the shared driver (`../driver/`).

`Gen.scala` generates one typed program per seed (see `../erasure/README.md` for the grammar): a trait/abstract class/class hierarchy with vals, vars, lazy vals, nested objects, overloads, overrides with super calls, default, by-name and vararg parameters; expressions with pattern matching on a sealed hierarchy, tuples, Options, extractors, guards and alternatives, for-comprehensions, try/catch/finally and returns through finally, tail and mutual recursion, local defs and classes, lambdas and SAM literals, partial functions, interpolation, named arguments, implicit classes and parameters, arrays and while loops, value classes, and an evaluation-order trace. Changes for the campaign: `@specialized` at weight 0 (`-Dw4p.spec`); `Main.run` calls one method per instance, ancestor view and value class, each with at most 12 member calls; numeric overloads are not generated side by side (they are ambiguous by the overloading rules once one is overridden). `-Dw4p.round=N` switches on the constructs added per round: 2, Int/Char/String literal switches with alternatives, guards and `@switch`; 3, structural (reflective) calls on a generic class and on anonymous classes, and `@varargs` members.

`Hunt.scala` compiles each program in these configurations concurrently and compares outcomes (printed output, or exception class) with the reference (build under test, default flags): `opt-local` (`-opt:local`), `delambdafy-inline`, `separate` (one unit at a time in dependency order), `v18` (2.13.18 compiler and library, same JVM), `ycheck` (`-Ycheck:all`, 1 seed in 10; anything the compiler prints is a difference), `inline` (`-opt:inline:** -opt:local`, 1 seed in 20 and only for sources up to 15,000 characters). Known signatures (GE6, GE4, WP1) are counted, not reported. The first program of each new signature is shrunk by deleting units and lines.

Run: `PACK=<build/pack> run.sh <first seed> <seconds> <out dir> [noshrink] [dump]`, with `JACOCO_EXEC=<file>` for coverage and `W4P_JAVA_OPTS` for `-Dw4p.round=3 -Dw4p.threads=8 -Dw4p.progPar=3`. Coverage: `cov.sh <exec> <xml>` prints line coverage of the transform, patmat, backend and typechecker packages and the methods with the most missed lines. `dump` also writes every configuration's outcome per seed.

Measured: one JVM with 12 permits, about 100 programs a minute (about 1,000 compilations) without JaCoCo and 34 with it; the spike driver did 6.3 on the same machine and generator. Two JVMs at 8 permits each: 32 and 13.5 a minute (the second under JaCoCo). `-opt:local` takes three to five times the reference's compile time on these programs (see GE6 in `../../known-signatures.md`).
