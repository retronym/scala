# Shared in-process compile-and-run driver

For harnesses that compile many small programs under several configurations and compare what they print. One JVM holds any number of Scala 2.13 compilers, each in its own class loader; every compilation gets a fresh `Global`, output stays in memory, and the configurations of one program compile and run concurrently.

- `Bridge.scala` (`scala.tools.nsc.W4Bridge`): compiled by each compiler under test with `build-bridge.sh <out> <name> <build/pack or jar list>`. It runs one compilation with a fresh `Global` into a `VirtualDirectory`, with class files of earlier units (separate compilation) put on the class path in memory, and returns the errors, the class files, and what the compiler printed to the console (`-Ycheck` complaints). A compiler crash comes back as one `CRASH <class>: <message> @ <first scala.tools frame>` line.
- `Driver.scala` (`w4d`): `Compiler(name, pack, bridgeDir)` loads a compiler with the platform loader as parent; programs it compiles run in a loader over the class files whose parent holds only that compiler's `scala-library.jar`, so a 2.13.18 program runs on the 2.13.18 library. `Config(name, compiler, flags, separate, rewrite)` is one way to build a program; `separate` compiles the units one at a time in the order given. `Driver.eval` / `evalAll` compile, load `Main` and call `run(): String`, returning an `Outcome(kind, text, log)` with kind `ok`, `run-throw` (text is the exception class), `compile-error`, `crash`, `timeout-compile` or `timeout-run`. `Pool` bounds concurrency with permits and a time limit per compile and per run; a timed-out thread is abandoned and counted in `stuck` (stop the run when it grows).
- The driver JVM's own class path needs only a `scala-library.jar` and the driver classes. JaCoCo: add `-javaagent:<org.jacoco.agent-0.8.13-runtime.jar>=destfile=<round>.exec,includes=scala.*` and run one JVM per round; the report against the jars of one build ignores classes of the others (JaCoCo matches classes by content).

Copy `Driver.scala` and `Bridge.scala`; see `../programs/run.sh` for the build and launch lines and `../programs/Hunt.scala` for a client with signatures and shrinking.

Measured with the program generator of `../programs` (five configurations per program: reference, `-opt:local`, `-Ydelambdafy:inline`, separate compilation, 2.13.18; `-Ycheck:all` on 1 in 10), 12 permits and 4 programs in flight on an 18-core laptop: about 100 programs a minute (about 1,000 compilations a minute) without JaCoCo. The spike driver (one compilation at a time, the inliner configuration every 8th program) measured 6.3 programs a minute on the same generator.
