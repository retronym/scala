# seeds track: existing run tests under metamorphic rewrites

`mklist.py` selects the single-file `run/*.scala` and `jvm/*.scala` tests of the compiler that have a `.check` file (944 kept, 269 excluded: `excluded.tsv`, mostly tests that extend `scala.tools.partest` classes, plus `//> using` directives other than `options`, stdin, `System.exit`, multi-file tests). `Driver.scala` compiles each in a fresh `Global` and class loader (60 s compile, 20 s run, stdout captured through `System.setOut` and `Console.withOut`) in the configurations `base`, `optlocal` (`-opt:local`), `delam` (`-Ydelambdafy:inline`), `nospec` (every `@specialized` and its argument list removed; skipped when nothing changes), `sepfwd` / `seprev` / `sepdep` (every top-level definition its own compilation, companions together, preceding imports repeated; in given order, reversed, and dependency order by retrying failed units), `xsource3`, `optinline` (`-opt:inline:** -opt:local`), `ycheck` (`-Ycheck:all`), `optdelam`. It writes `<out>/<seed>.<config>.txt` (outcome kind, then output); `compare.py` compares each configuration with `base` after normalising addresses, lambda and anonymous class numbering, line numbers and timings. 2.13.18: run `base` with `run.sh` on a directory holding `jars.txt` (the three 2.13.18 jars) and copy the files in as configuration `v18`.

Run: `run.sh <build/pack> seeds.tsv <out> <config,config> <part> <parts> <seconds>` with `W4S_CLASSES` set to the compiled driver, one process per part (JaCoCo through `W4S_JAVA_OPTS`). The driver resumes (skips existing outcome files) and stops after three timeouts, so wrap it in a retry loop. `covsum.py` prints line coverage of the transform, backend and typechecker packages and the largest unreached methods from a JaCoCo XML.

Measured: 944 seeds times three configurations in about 7 minutes with two JVMs and the JaCoCo agent; about 0.3 s per compile and run.

Not done: tests that extend partest classes (251), junit-based tests (need the testkit and junit on the class path), `-Xasync` programs, comparing stack traces.
